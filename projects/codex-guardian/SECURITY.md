# Security policy

Codex Guardian is a focus utility, not a security boundary. Still, please report
code-execution, privilege, path-matching, unsafe mutation, recovery, or release-
integrity vulnerabilities privately before opening a public issue.

Use GitHub's private vulnerability reporting for the
[`InternalAgencyIO/InternalAgency`](https://github.com/InternalAgencyIO/InternalAgency)
repository when available. Otherwise follow the contact route in the repository's
root [security policy](https://github.com/InternalAgencyIO/InternalAgency/blob/main/SECURITY.md).

Include the Guardian version, Windows version, a minimal reproduction, expected
behavior, and impact. Remove usernames, local paths, device identifiers, and log
content that is not essential to the report.

Only the latest stable Guardian release is supported with security fixes.
