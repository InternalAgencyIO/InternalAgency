# STAR ASCENT

This directory is the migration marker for the STAR ASCENT public project.
It deliberately contains no application implementation: the live bilingual
website and its launch archive are moving to dedicated repositories so that
Radiance remains cleanly independent.

See [the repository architecture](../../docs/REPOSITORY_ARCHITECTURE.md) for
the public repository map and publishing rules.

## Planned public homes

- `star-ascent-site` — English and Turkish site source.
- `star-ascent-contracts` — reviewed technical implementation and tests.
- `star-ascent-audits` — review scope, findings, and remediation evidence.
- `star-ascent-archive` — public Dossier editions and launch record.

Until those repositories exist, do not place wallet material, credentials,
private drafts, or alleged on-chain evidence here.
