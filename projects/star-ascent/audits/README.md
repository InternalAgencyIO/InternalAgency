# STAR ASCENT audit record

This is the public record for independent review. It is not an audit attestation.

## What can be reviewed now

- Website source, bilingual public copy, and designed Dossier routes.
- Launch schedule checks and deterministic validation scripts.
- Token design target: fixed 1,000,000,000 IAT maximum supply, with proposed
  public time-locks for non-circulating allocations.
- Required evidence order before any distribution.

## What is not yet proven

- A mainnet mint address.
- Initial supply and decimal configuration on-chain.
- Mint/freeze authority revocation.
- Allocation wallets or time-lock accounts.
- Any distribution or claim route.

## Review standard

Do not accept screenshots, DMs, or a written claim as proof. A launch-critical
statement becomes verified only when its direct public evidence can be checked
against the website, pinned announcement, and live broadcast.

The current site validation scripts are available in
[site/scripts](../site/scripts). Findings, external reviews, and remediation
notes should be added here as dated records once they exist.
