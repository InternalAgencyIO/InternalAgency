# B3 canonical source lineage — 2026-08-08

This package records the explicit transition from the retained IAT V2 architecture-work audit to the public B3 forward architecture.

The V2 audit remains a historical snapshot authenticated by its original commit, Git tree, manifest digest, and internal artifact hashes. It is not relabeled as proof of the current B3 release. Its historical commit does not need to be an ancestor of every future B3 checkout.

The separate B3 successor binding must exist, match its Git tree, and remain an ancestor of the checkout being validated. This keeps the current-source check on the B3 lineage without rewriting the V2 evidence package.

This lineage record grants no deployment, funding, signing, broadcast, or Mainnet authority. Mainnet remains `UNSCHEDULED_HOLD`.
