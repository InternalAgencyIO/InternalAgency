# Genesis / Public Build Brief

STAR ASCENT is being built in public as a culture, technology, and community project. The website is the signal surface; the Dossier is the canonical document index; the repository is the durable record of the construction.

## What is live today

- Bilingual public experience with host-based English/Turkish selection.
- Story-led Genesis visual system and production artwork.
- White Dossier and supporting public documents presented through designed Dossier routes; legacy source records are preserved in the project archive.
- Activation Terminal that makes the launch sequence legible without pretending a claim flow is active.

## What must be verified at Genesis

1. Exact token mint address and token program.
2. Initial supply and decimals.
3. Mint and freeze-authority revocation evidence.
4. Allocation wallets and time-lock addresses.
5. Circulating-supply calculation.
6. Official distribution or claim method, if one is activated.

If any field is missing, contradictory, or cannot be independently checked, the public status is **HOLD**.

## Language and tone

The project speaks in a mythic, contemporary science-fiction register: decisive, beautiful, and specific. Public creative language must never be used to disguise an unverifiable technical claim.

## The Activation Terminal

The terminal is a user-experience shell for the Genesis sequence. It does not persist a callsign, connect a wallet, collect identity data, initiate a transaction, or create eligibility. Its purpose is preparation and verification literacy.
