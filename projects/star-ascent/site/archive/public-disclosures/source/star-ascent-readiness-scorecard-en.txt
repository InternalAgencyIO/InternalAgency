PRE-LAUNCH CONTROL DOCUMENT — NOT LAUNCH APPROVAL

CURRENT DECISION: HOLD

PUBLICATION STOPLINE

Before posting, pinning, reading aloud, or linking any token address, the
operator must read the current decision and evidence freshness gate. If either
is HOLD, missing, expired, or inconsistent, stop the publication and record
the issue for review. Do not substitute a draft, rehearsal artifact, or
unverified screenshot for public evidence.

This scorecard records whether launch-critical public evidence is complete,
current, and consistent. Rehearsal completion, a passing local test, or a
finished draft does not change a HOLD item to READY.

READINESS GATES

1. TOKEN IDENTITY — HOLD
Required:
- Official mint address
- Token program
- Decimals
- Final on-chain supply
- Direct explorer link
- UTC checked-at timestamp
- Named review role

2. AUTHORITY STATE — HOLD
Required:
- Direct explorer evidence for current mint authority
- Direct explorer evidence for current freeze authority
- Intended final state
- Independent review record

3. ALLOCATION AND RELEASE CONTROLS — HOLD
Required:
- Recipient categories and exact token amounts
- Labeled public wallets
- Mathematical total of 100%
- Vesting, lock, custody, and release terms
- Public reporting method for every distribution

4. CHANNEL CONSISTENCY — HOLD
Required:
- Website, pinned official announcement, and livestream values match
- Full address comparison, character for character
- Final bilingual copy review
- Public links work without a wallet connection

EVIDENCE FRESHNESS GATE

Every record must include:
- A direct public link
- A UTC checked-at timestamp
- The named role that performed the check
- The value that was observed

Recheck all launch-critical evidence at T−60 minutes and immediately before
publishing any address or opening registration. A missing timestamp,
unavailable link, changed value, or cross-channel mismatch returns the launch
to HOLD.

DECISION RULE

READY may be recorded only when every gate has current linked evidence and two
separated review roles agree. Any HOLD or FAIL blocks address publication,
registration opening, and distribution.

No numerical readiness percentage is used while critical evidence is missing.
This document never requests or contains a seed phrase, private key, password,
personal data, payment, or community funds.
