IAT TOKENOMICS // CANONICAL PRE-LAUNCH DRAFT
Version 1.0 — 27 July 2026

This document fixes the intended economic design for $IAT. It is a pre-launch specification, not evidence that a token, lock wallet, authority change, or distribution has occurred. Those facts become public only when they are linked from the official site and independently verifiable on Solana.

01 // FIXED SUPPLY
Maximum supply: 1,000,000,000 IAT
Additional issuance: none intended.
After the documented initial mint, the mint authority and freeze authority are to be permanently revoked. The explorer evidence, transaction signatures, final mint address, token program, decimals, and UTC verification time must be published before any public distribution begins.

02 // ALLOCATION
Community distribution — 50.00% — 500,000,000 IAT
Treasury / long-term build — 20.00% — 200,000,000 IAT
Ecosystem / collaborators — 15.00% — 150,000,000 IAT
Core team — 10.00% — 100,000,000 IAT
Liquidity / launch operations — 5.00% — 50,000,000 IAT
Total — 100.00% — 1,000,000,000 IAT

03 // RELEASE AND LOCKING
No private sale. No presale. No paid registration. No promised yield.

Community distribution is released through announced public campaigns and claim windows; the allocation method, eligibility rules, public wallet list where applicable, and release schedule must be published before each release.

Treasury / long-term build: public time-lock wallet; 12-month cliff, then linear release over 36 months.

Ecosystem / collaborators: public time-lock wallet; 6-month cliff, then linear release over 24 months. Any recipient allocation requires a public category, amount, lock address, and release terms before transfer.

Core team: public time-lock wallet; 12-month cliff, then linear release over 36 months. No discretionary early unlocks.

Liquidity / launch operations: only the documented launch allocation may be made available at genesis. The receiving wallet, liquidity venue if any, transaction evidence, and remaining reserve status must be public. Any amount not actively deployed remains in a public time-lock wallet.

04 // PUBLIC PROOF STANDARD
Before distribution, the official website must publish one evidence packet containing:
- Final mint address and token program
- Exact total supply and decimals
- Explorer links proving mint and freeze authority status
- Every allocation wallet, percentage, amount, and lock/release terms
- Lock contracts or wallet control model, including a verification method
- A clear circulating-supply calculation at genesis

Until that packet is published, every allocation is pending. A logo, a screenshot, an influencer post, or a direct message is not proof.

05 // ASSOCIATE DLC
Associate DLC is scheduled as a non-custodial affiliation and vouching layer after genesis. It does not custody $IAT, ask for secret phrases, create a financial return, or promise an APY. Any future incentives require a separate public proposal defining funding source, formula, eligibility, governance process, duration, and risks before they exist.

06 // BOUNDARY
$IAT is a speculative community token and not a claim on revenue, equity, profit, or a guaranteed return. No one is asked to send money to Internal Agency or a founder to participate. Never share a seed phrase or private key; never trust an address until it matches the official website and livestream screen.
