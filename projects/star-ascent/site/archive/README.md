# Iteration Archive

The Git commit graph is the primary preserved archive of the live build. This directory is the human-readable index for the working method.

## Evidence hierarchy

1. Signed, independently verifiable on-chain evidence where applicable.
2. Public source and the immutable Git commit that produced a deployment.
3. Directly served public documents and their versioned paths.
4. Screenshots, social posts, and commentary as supporting context only.

## Current archive surfaces

- `CHANGELOG.md` — public website and document evolution.
- `docs/GENESIS.md` — launch truth boundary and public build brief.
- `archive/public-disclosures/source/` — canonical disclosure sources retained behind designed Dossier redirects.
- `public/images/` — versioned visual lore assets used in each build.

Do not treat this archive as proof of an unaudited technical claim. It is proof of the work, source evolution, and declared public process.
