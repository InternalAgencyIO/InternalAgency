# Deliverables

The final 4K master is published as a GitHub Release asset to avoid storing a
large binary in regular Git history.

- `master-verification.json` records the independently decoded frame count,
  duration, stream contract, byte count, FFprobe version, and SHA-256.
- `SHA256SUMS.txt` is suitable for `Get-FileHash` or `sha256sum` comparison
  after downloading the release asset.
- `RELEASE_NOTES.md` records the public release scope and the honest
  photo-film/full-motion distinction.

Release asset: `NIGHTFLIGHT-Guardian-Film-v1.0.0-2160p-H264.mp4`
