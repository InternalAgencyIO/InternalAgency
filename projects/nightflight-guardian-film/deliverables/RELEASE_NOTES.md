# NIGHTFLIGHT: Signal Four Reunion v1.0.0

The release contains one silent, video-only 4K H.264 master assembled from six
exact 15-second cinematic photo-film scenes.

- Resolution: 3840 x 2160
- Frame rate: 30 fps
- Frames: 2,700
- Runtime: 90.000 seconds
- Audio, dialogue, titles, captions, and subtitles: none
- Codex Guardian practical: Scene 1 frames 0-299 only (10.000 seconds)
- Master SHA-256:
  `a0e1a8e7fd4e9cca548bda85589dc28bc732b0ab5be6d95a2b8f7ac4cfd1b549`

The four women are project-generated fictional adults aged 25 or older and no
real-person face references were used. The scenes are fully clothed,
consensual, romantic, and non-explicit.

This is an animated photo-film made from approved 1672 x 941 photoreal
keyframes using deterministic camera moves and restrained temporal film
texture. It is not described as native 4K photography or generated character
motion. The unsuccessful experimental FramePack attempt generated no usable
output and is documented in `production/FRAMEPACK_ATTEMPT.md`.
